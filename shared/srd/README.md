# shared/srd — compiled 5e SRD data

Generated by `npm run build:srd` (`scripts/build-srd.mjs`) from `data-src/srd-raw/5e-SRD-*.json`
(5e-bits/5e-database, SRD 5.1). **Do not edit by hand** — change the build script and rebuild.
Licence and attribution: [LICENSE.md](LICENSE.md).

Every file is a JSON array; every entry has an `index` (kebab-case slug, the SRD API index). Shared modules never
import these files: the server reads them with `fs`, the client fetches `GET /api/srd/:name`, and both pass them to
`shared/rules.js` / `shared/charbuild.js` as `srd = { classes, races, backgrounds, spells, equipment, features,
conditions, skills, magicItems, languages, monsters? }`. Use `byIndex(list)` from `shared/rules.js` for lookups.

Conventions: ability keys `str dex con int wis cha`; skill keys camelCase (`animalHandling`, `sleightOfHand`);
distances in **feet**; costs in **gp** (1 sp = 0.1); weights in lb. Proficiencies (armor, weapons, tools,
languages) are stored as display **names** (`"Martial Weapons"`, `"Longswords"`, `"Thieves' Tools"`); rules match
them leniently with `normName()` (case/plural/word-order insensitive).

`specific` keys (camelCase of the SRD `class_specific`, only those the class has): barbarian `rageCount` (9999 =
unlimited), `rageDamage`, `brutalCriticalDice`; bard `bardicInspirationDie`, `songOfRestDie`, `magicalSecretsMax5/7/9`;
cleric `channelDivinity`, `destroyUndeadCr`; druid `wildShapeMaxCr`, `wildShapeSwim`, `wildShapeFly`,
`wildShapeUses`; fighter `actionSurges`, `indomitableUses`, `extraAttacks`; monk `martialArts: "1d6"`, `kiPoints`,
`unarmoredMovement`; paladin `auraRange`, `channelDivinity`; ranger `favoredEnemies`, `favoredTerrain`; rogue
`sneakAttack: "3d6"`; sorcerer `sorceryPoints`, `metamagicKnown`; warlock `invocationsKnown`,
`mysticArcanumLevel6..9`; wizard `arcaneRecoveryLevels`.
